## What is intentionally not here

This site documents **behaviour**, not anyone's code. It excludes vendor
binaries, decompiled driver source, MCU firmware images, configuration blobs,
key material and captured biometrics. See the
[provenance notes](https://github.com/delitdesnoyers06-del/goodix-gxfp-protocol/blob/main/PROVENANCE.md)
for the exact line and why.

## Companion driver

The notes document the protocol implemented by the **GXFP51A7 port** of
libfprint-goodixtls:

- [delitdesnoyers06-del/libfprint-goodixtls](https://github.com/delitdesnoyers06-del/libfprint-goodixtls)
  — the port, adding the Huawei MateBook 13 2019 (`WRT-WX9`, MilanL) alongside
  the original GXFP5187 support.
- [Sigfrodr/libfprint-goodixtls](https://github.com/Sigfrodr/libfprint-goodixtls)
  — the upstream TOD driver by Benjamin Allègre, for the MateBook X Pro
  (`MACH-WX9`, GXFP5187).
